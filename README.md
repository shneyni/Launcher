# Launcher

Launcher ל־Android המיועד למכשירים עם מקשי ניווט פיזיים ולמסכי 3:4 קטנים. הפרויקט נכתב ב־Kotlin ומשתמש ב־Views רגילים, כך שאין תלות במגע או בערכת UI חיצונית. `applicationId` נשמר קבוע כ־`il.co.maqshim.launcher`; אין לשנותו בעדכונים.

## פתיחה ובנייה

פתחו את התיקייה הזו ב־Android Studio וסנכרנו Gradle. נדרשים Android SDK 35 ו־JDK 17. כדי לקבוע את Launcher כמסך הבית, התקינו והריצו אותו ואז בחרו בו במסך בחירת אפליקציית הבית של Android.

## APK ועדכונים

GitHub Actions בונה APK בכל דחיפה ל־`main`. בלי מפתח חתימה מוגדר, נשמר Artifact בשם `Launcher-debug-test-only`; זהו APK לבדיקה בלבד, ואין להפיץ אותו כעדכון. עם מפתח חתימה, נבנה APK חתום ונוצרת גרסת GitHub Release. מספר `versionCode` נלקח ממספר הריצה של ה־workflow ולכן עולה בכל ריצה חדשה.

כדי לאפשר התקנה של עדכון על גרסה קיימת, יש לשמור את אותו מפתח חתימה בכל הבניות. מאגר GitHub אינו מכיל את קובץ המפתח. פתחו `signing/Prepare-GitHubSecrets.ps1` ב־PowerShell כדי להעתיק ללוח את קידוד Base64 של הקובץ. ב־GitHub פתחו **Settings → Secrets and variables → Actions** והוסיפו Repository secrets בשם `ANDROID_KEYSTORE_BASE64` (הדביקו את תוכן הלוח) ו־`ANDROID_KEYSTORE_PASSWORD` (התוכן של `signing/keystore-password.txt`). ה־workflow קורא את alias של המפתח אוטומטית. שמרו עותק גיבוי של keystore והסיסמה במקום מאובטח; איבוד המפתח מונע חתימה של עדכונים תואמים. תיקיית `signing/` מוחרגת מהעלאה למאגר.

## מקשים

- חצים: מעבר בין פריטים; ברשת האפליקציות שמאלה/ימינה עוברים בין תאים ובמעלה/מטה בין שורות.
- מרכז/Enter: פתיחת אפליקציה, סימון פריט בניהול או בחירה/שחרור של פריט בסידור. **לחיצה ארוכה** על אפליקציה פותחת תפריט: פתח / פרטי אפליקציה / הסר אפליקציה.
- `KEYCODE_SOFT_LEFT`: קיצורים ממסך הבית, אפשרויות במסכי הרשימות, ושמירה בניהול ובסידור.
- חזרה: במסך הבית פותחת אנשי קשר; בתפריט סוגרת אותו; במסכים האחרים חוזרת למסך הקודם.
- **בית**: כל לחיצה על מקש הבית (מכל אפליקציה, ומכל מסך ב־Launcher) מחזירה למסך הבית.
- **לחיצה ארוכה על `#`** מכל מקום במכשיר: מחליף בין צליל ← רטט ← שקט (דורש את שירות המקשים, ראו למטה). לחיצה קצרה היא `#` רגיל. כשהסמן בשדה טקסט, גם לחיצה ארוכה עוברת כרגיל.
- **לחיצה ארוכה על מקש ההפעלה**: תפריט הפעלה עם סמלים — נעילה, כיבוי, הפעלה מחדש, Bluetooth, Wi‑Fi, צליל, רטט ושקט. סמל פעיל לבן, כבוי אפור שקוף.

## רקע

מסך הבית מציג את רקע המסך של המכשיר, ומתעדכן אוטומטית כשמחליפים אותו. במסך האפליקציות אותו רקע מוצג כהה, מטושטש ומוגדל מעט. ב־Android 13 ומעלה צריך לאשר „גישה לקבצים (לרקע)” ב: אפשרויות ← הגדרות מערכת; בגרסאות ישנות יותר „גישה לרקע ולתמונת הנעילה”.

## אפליקציית טלפון

האפליקציה יכולה לשמש כאפליקציית הטלפון של המכשיר (אפשרויות ← הגדרות מערכת ← „אפליקציית טלפון”). אחרי ההגדרה:

- **חיוג:** הקלדת ספרות במסך הבית פותחת חייגן. שורה ראשונה: חיוג למספר שהוקלד; מתחתיה אנשי קשר שמתאימים לפי שם (מקשי T9, עברית ואנגלית) או לפי חלק מהמספר. חצים לבחירה, מקש חיוג / אישור / מקש שמאל להתקשרות, אחורה מוחק, `0` ארוך מקליד `+`.
- **מסך שיחה משלנו:** מקש חיוג = מענה, מקש סיום = דחייה/ניתוק, מקש שמאל = רמקול, מקש ימין = השתק, חץ למעלה = המתנה, ספרות = צלילי חיוג (DTMF).
- **היסטוריית שיחות:** מקש החיוג הירוק במסך הבית, כשלא הוקלדה ספרה, פותח את היסטוריית השיחות (↙ נכנסת, ↗ יוצאת, ✗ שלא נענתה). אישור או חיוג מתקשרים חזרה.
- **חזרה לשיחה:** בזמן שיחה מופיע כרטיס ירוק במסך הבית.

אם משהו משתבש אפשר להחזיר את אפליקציית הטלפון של המכשיר דרך הגדרות Android ← אפליקציות ברירת מחדל.

## התראות במסך הבית

מתחת לתאריך מופיעים (רק כשיש מה להציג) שלושה כרטיסים צהובים: שיחות שלא נענו, הודעות שלא נקראו, ושיר שמתנגן. דורש להפעיל **גישה להתראות** ל־Launcher (אפשרויות ← הגדרות מערכת ← „גישה להתראות ולמוזיקה”).

- חץ למטה/למעלה: מעבר בין הכרטיסים (בלי כרטיס נבחר, מקש אישור פותח את רשימת האפליקציות).
- שיחות / הודעות: אישור פותח את ההתראה באפליקציה שלה.
- שיר: אישור עוצר או ממשיך, לחיצה ארוכה פותחת את האפליקציה, ימינה שיר הבא, שמאלה שיר קודם.
- במסך הנעילה אותם כרטיסים מוצגים לקריאה בלבד.

## מסך נעילה

מסך נעילה משלנו מוצג מעל זה של המכשיר ואינו מדליק את המסך בעצמו, ומציג את תמונת הנעילה (או הרקע) שהוגדרה במכשיר. פתיחה: לחיצה אחת על מקש שמאל.

כדי שזה יעבוד: בהגדרות Android יש לקבוע נעילת מסך **ללא** (לא PIN/דפוס), לאשר „הצגה מעל אפליקציות” ל־Launcher, ולהפעיל את שירות המקשים. הכול נגיש מ**אפשרויות ← הגדרות מערכת** בתוך האפליקציה.

הניווט בין פריטים מעדכן רק את ההדגשה (בלי לבנות מחדש את המסך), ורשימת האפליקציות נטענת מחדש רק כשמותקנת או מוסרת אפליקציה. שירות המקשים מציג את מסך הנעילה בעצמו, גם בלי הרשאת „הצגה מעל אפליקציות”, ומעביר אליו את מקש שמאל.

## ללא אנימציות וללא מגע

כל אנימציות החלונות והמעברים כבויים (ערכת נושא, `overridePendingTransition`, גלילה ללא החלקה). כל המסכים בולעים אירועי מגע ותנועת עכבר; ההפעלה היא במקשים בלבד.

## פרטיות והרשאות

היישום מבקש `READ_PHONE_STATE` רק כשנמצא SIM ושם המפעיל דורש הרשאה. לפני בקשת Android מוצג הסבר. סירוב אינו חוסם שימוש ב־Launcher. אנשי קשר נפתחים באמצעות Intents סטנדרטיים, ללא קריאת מאגר אנשי הקשר או בקשת הרשאה אליו.

רשימת האפליקציות מגיעה מפעילויות Launcher שהמערכת חושפת דרך `PackageManager`; הרשאות package visibility מוגדרות ב־manifest. בחירת הקיצורים, סדרם והעדפותיהם נשמרים ב־SharedPreferences.

## תכנון חזותי

הסגנון נשען על [ממשק NokiaMusic](https://github.com/shneyni/NokiaMusic): משטח שחור, טקסט לבן ואפור, צהוב `#FDC100`, ושורת מצב קטנה. במאגר נמצאו אייקוני launcher וקטוריים ואייקוני שורת מצב מצוירים בקוד, אך לא סט אייקונים למסכים; לכן אייקון ה־launcher הועתק, סמלי שורת המצב שוחזרו מתוך ציורי המקור, ונוספו אייקוני PNG ל־SIM, ל־SIM חסר, לאנשי קשר ולקיצורים.
